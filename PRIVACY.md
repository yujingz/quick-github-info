# Quick GitHub Info Privacy Policy

Quick GitHub Info does not collect, store, sell, or transfer personal data.

The extension runs on Google Search result pages and reads page hyperlinks only to identify GitHub repository links. When a GitHub repository link is found, the extension sends the public repository owner/name to GitHub's public API to retrieve repository metadata, including language, star count, and fork count.

The extension uses this metadata only to display repository information next to the matching Google Search result. It does not track browsing history, clicks, keystrokes, mouse movement, location, authentication information, financial information, health information, personal communications, or personally identifiable information.

No user data is used for purposes unrelated to the extension's single purpose, sold to third parties, or used to determine creditworthiness or for lending purposes.
